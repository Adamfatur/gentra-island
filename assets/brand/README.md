# Gentra Island logo

| File | Use |
|---|---|
| `gentra-island-wordmark.svg` | One line, takes the text color around it (`currentColor`) |
| `gentra-island-wordmark-white.svg` / `-black.svg` | One line, fixed white or near-black |
| `gentra-island-stacked*.svg` | GENTRA over ISLAND, for square spaces |

The lettering is set in **Marow Block** by Ramandhani and converted to outlines, so no font file is needed or included. The font itself is licensed separately and is not part of this repository.

Logo by Adam Faturahman.
